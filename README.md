# 🎬 Сцена после титров — автопостинг

Бот сам публикует новости кино в Telegram-канал: около 20 постов в день, раз в час с 6:00 до 1:00 по Москве.
Всё работает бесплатно на GitHub Actions.

## Что делает каждый запуск
1. Собирает свежие новости (за последние 12 ч) из Variety, Deadline, THR, IndieWire, Collider, KinoNews, Google Новостей и других.
2. ИИ-редактор выбирает самую интересную тему, которой ещё не было в канале, и чередует рубрики.
3. **Проверка достоверности:** новость считается подтверждённой, если о ней пишут 2+ источника или её дали отраслевые издания (Variety / Deadline / THR). Неподтверждённая новость выходит с пометкой «🤫 Пока это слухи».
4. ИИ пишет пост, а затем отдельный ИИ-фактчекер сверяет каждый факт с исходными статьями и убирает всё, чего там нет.
5. Картинка: кадр или постер фильма, фото актёра (TMDB) → фото из статьи → фирменный баннер (только если ничего не нашлось).
6. Если новость про трейлер, в посте будет плеер YouTube.

## Настройка (один раз, ~20 минут)

### 1. Бот
- @BotFather → `/newbot` → сохраните **токен**.
- Канал → Администраторы → добавьте бота с правом «Публикация сообщений».
- Откройте своего бота в Telegram и нажмите **Start** (иначе он не сможет писать вам в личку).
- Узнайте свой ID: напишите @userinfobot, он ответит числом — это **ADMIN_CHAT_ID**.

### 2. Ключи
- **Gemini:** aistudio.google.com → Get API key → Create API key (из России может понадобиться VPN).
- **TMDB:** themoviedb.org → Настройки → API → создать ключ (personal use).

### 3. Репозиторий на GitHub
1. github.com → **New repository** → имя `scena-posle-titrov` → **Private** → Create.
2. Нажмите **uploading an existing file** и перетащите **все файлы и папку `fonts`** из архива → **Commit changes**.
3. Файл расписания создайте вручную (папки с точкой в названии часто скрыты на компьютере):
   **Add file → Create new file**, в поле имени введите `.github/workflows/post.yml`,
   вставьте содержимое файла `post.yml` из архива → **Commit changes**.

### 4. Секреты
**Settings → Secrets and variables → Actions → New repository secret**, добавьте по одному:

| Имя | Значение |
|---|---|
| `TELEGRAM_BOT_TOKEN` | токен от BotFather |
| `TELEGRAM_CHANNEL` | `@имя_канала` |
| `ADMIN_CHAT_ID` | ваш ID от @userinfobot |
| `GEMINI_API_KEY` | ключ Gemini |
| `TMDB_API_KEY` | ключ TMDB |

На той же странице откройте вкладку **Variables** → **New repository variable**:
`POST_MODE` = `moderation`

### 5. Проверка
**Actions → «Пост в канал» → Run workflow.** Через 1–2 минуты пост придёт вам в личку.
Дальше бот сам запускается каждый час.

## Режимы
- `POST_MODE = moderation`: посты приходят **вам в личку**, канал не трогается. Удобно, чтобы первые дни оценить качество.
- `POST_MODE = auto`: посты идут **в канал**. Переключение: Settings → Secrets and variables → Actions → Variables → POST_MODE → `auto`.

## Если что-то не так
- **Actions → последний запуск → шаг «Сделать и опубликовать пост»**: там подробный лог (какие ленты не ответили, какая тема выбрана, что поправил фактчек).
- Изменить время: строка `cron` в `.github/workflows/post.yml` (время в UTC = МСК − 3).
- Добавить или убрать источники: файл `sources.py`.
- Стиль текста: правила `WRITE_RULES` в `main.py`.
